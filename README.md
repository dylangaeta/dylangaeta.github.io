# dylangaeta.com

Personal academic website for **Dylan C. Gaeta, Ph.D.** — Postdoctoral Research Associate at CIRES (CU Boulder) and the NOAA Global Monitoring Laboratory.

Live site: **[dylangaeta.com](https://dylangaeta.com)**

## Stack

Plain HTML + CSS. No build step. Hosted on GitHub Pages with a custom domain.

## Local preview

Open `index.html` directly in a browser, or run any static server from the project root:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Structure

```
index.html              — page markup
style.css               — styles
CNAME                   — custom domain (dylangaeta.com)
favicon.svg / *.png     — favicons
uploads/                — CV, hero photo, figures
```

## Deployment

Pushes to `main` are deployed automatically by GitHub Pages.
